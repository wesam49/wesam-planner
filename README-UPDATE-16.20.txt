Wesam Planner – Update 16.20

Einnahmen-Korrektur:
- Automatische Einnahmen (VMT, Bib, Brunner, Zusatzjob) können im Finanzbereich angepasst werden.
- Die ursprüngliche Berechnung aus Kalender/Gehalt bleibt sichtbar.
- Korrektur wird separat als +/− Betrag gespeichert und direkt am Eintrag angezeigt.
- Optional kann eine Notiz zur Korrektur gespeichert werden.
- Finanzsummen, Jahreswerte und Sparberechnungen verwenden den korrigierten Betrag.
- Die Gehalt-Seite bleibt die berechnete Originalquelle und wird nicht überschrieben.

Google-Anmeldung am Laptop:
- Desktop-Anmeldung nutzt jetzt den zuverlässigeren Redirect-Flow statt nur Popup.
- Der Button wird explizit aktiviert und zeigt einen Status beim Start der Anmeldung.
- cloud.js wird in Version 16.20 aktualisiert.

Alle Funktionen aus 16.19 bleiben erhalten.
