Wesam Planner – Update 16.5

Neu:
1. Bisher gespart ist jetzt jahresübergreifend. Ersparnisse werden beim Wechsel in ein neues Jahr nicht mehr auf null gesetzt.
2. Sparziele haben eine eigene Monatsnavigation. Auch zukünftige Monate können als Prognose angezeigt werden, basierend auf bereits geplanten Einnahmen, Ausgaben und Arbeitszeiten.
3. Neuer Kalendertyp "Zusatzjob".
4. Für Zusatzjobs können eigene Gehaltsregeln pro Termin festgelegt werden:
   - Jobname
   - Stundenlohn
   - Abzug in %
   - Nacht-, Sonntags- und Feiertagszuschlag in %
   - fester Zuschuss
   Das Ergebnis wird automatisch in Gehalt, Finanzen und Übersicht eingerechnet.
5. Jahresübersicht zeigt zusätzlich:
   - Einnahmen gesamt
   - Ausgaben gesamt
   - Jahresersparnis
   - Ø monatliches Einkommen
   - Ø monatliche Ausgaben
