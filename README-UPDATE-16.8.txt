Wesam Planner – Update 16.8

Jahresübersicht
- Der obere Zeitraum-&-Jahresziele-Rechner ist vollständig vom Jahresblock unten getrennt.
- Die unteren Durchschnittswerte beziehen sich immer nur auf das angezeigte Jahr.
- Monatszeilen zeigen Monat + Jahr, z. B. April 2026.

Zusatzjob
- Jeder einzelne Arbeitstag hat einen eigenen Auszahlungsmonat.
- Das Bearbeiten eines einzelnen Tages verändert keine anderen Zusatzjob-Termine.
- Auch wenn nur der Auszahlungsmonat geändert wird, wird diese Änderung gespeichert.
- Mehrfach erstellte Tage können danach einzeln unterschiedliche Auszahlungsmonate bekommen.
